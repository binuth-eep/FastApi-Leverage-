# Academy illustrations

Generated with the built-in `image_gen` tool. WebP copies are also embedded in `index.html`, so the course still opens as a single offline file. Encoding to WebP preserves the generated composition and dimensions.

## learning-world.webp

Use case: stylized-concept. Asset type: hero illustration for a cheerful Sinhala backend coding academy website, landscape 3:2 illustration. Primary request: a delightful premium 3D clay miniature world about learning backend development: a lavender laptop open with simple abstract colored code strokes, chunky mint database cylinders connected by a little coral pathway, a tiny golden rocket lifting beside the laptop, a potted plant and a few floating geometric shapes. No people. Style: sophisticated playful soft clay 3D editorial illustration, rounded sculptural objects, tactile matte material, soft shadows and ambient occlusion, crisp beautiful detail. Palette: lilac, periwinkle, peach coral, mint green, sunny apricot. Backdrop: solid very pale lavender #eeeafa, seamless studio floor with soft lavender shadows. Composition: full cluster centered, all objects entirely in frame, generous pale lavender breathing room around edges so image integrates into a lavender web banner, no border. Lighting: warm friendly studio sunlight, soft realistic shadows. Constraints: no text, no letters, no watermark, no logos, no UI screenshot, no photorealistic people.
